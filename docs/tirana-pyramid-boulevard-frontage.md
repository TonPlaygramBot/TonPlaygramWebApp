# Dëshmorët e Kombit: Pyramid frontage

Public exterior visual textures/geometry only. No gameplay navigation, camera, building footprints, collisions or routes are changed. These renderer models are artistic interpretations, not surveys; no third-party source photos, logos or plans are distributed.

| Site | Evidence | Changed |
| --- | --- | --- |
| Piramida | [MVRDV realised project and exterior photographs](https://www.mvrdv.com/projects/312/the-pyramid-of-tirana?photo=20023), [Albanian National Tourism Agency](https://akt.gov.al/en/attractions/the-pyramid-of-tyranny/), [Piramida Center public programme](https://piramida.edu.al/wp-content/uploads/2023/05/Call-for-Expression-by-Piramida-Center_Second-Phase.pdf) | Coloured rooftop and base volumes, glazing, an uninterrupted slope, and no fictional commercial sign on the roof. The virtual mall route and gameplay remain unchanged. Placement, size, colours and count of decorative elements are approximate. |
| Laguna · Bulevardi | [Operator branch page](https://laguna.al/laguna-1-bulevardi/), [OSM footprint](https://www.openstreetmap.org/way/1111613943), [exterior reference](https://wikimapia.org/41745155/Laguna) | The dated “Dëshmorët e Kombit” and modern Bajram Curri addresses refer to the first-branch corner kiosk. The visual shell now matches the venue type (single storey, glazed service counter, dark frame and teal strip) rather than an 18 m generic apartment. Only this branch is restyled. |
| Bar West | [Municipal venue listing](https://tirana.al/pika-interesi/west), [OSM café point](https://www.openstreetmap.org/node/12779107687), [Matilda Karçanaj exterior photograph](https://www.spottedbylocals.com/tirana/west-bar/) | The previous automatic storefront match omitted it. A ground-floor sign and small terrace with cream parasols, dark chairs and wooden tables use the public Twin Towers frontage. Furniture count and position, sign styling and display dimensions are approximations, not a reconstruction of the interior. |
| Rogner Hotel | [Official exterior gallery](https://www.hotel-europapark.com/en/overview/gallery/hotel.html), [mapped main entrance](https://www.openstreetmap.org/node/6498475597) | Pale curved shell and segmented glazed entrance canopy in the same previous envelope. |

The two game implementations already consume `NativeLandmarkLayer`, `ReferenceFacades` and shared `WorldEnhancements`/`StreetLifeLayer`. The latter has a single optional instanced parasol draw only when the café geometry is selected. Route ribbon exclusions are retained. Mapped source attribution: © OpenStreetMap contributors, ODbL.
