# Tirana corridor surface art, shared by Streets and Racing

This release applies seven authored asphalt/pavement treatments to nine named mapped roads. It uses existing materials, world-space wear, original anti-aliased paver bonds and soft shoulder weathering on existing road polygons: no imported imagery, new textures, placement data, geometry, lane markings or race/collision changes. Only the mapped segments and sidewalk meshes derived from them are styled. This is not a survey of pavement, a change to street topology, or a depiction of completed future works. Unnamed and differently named roads, including the separate Rruga Gjergj Fishta, keep the current citywide treatment.
