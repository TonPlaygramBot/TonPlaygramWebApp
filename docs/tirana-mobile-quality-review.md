# Tirana Streets mobile quality pass

Starting revision: `0c6b83e` on `main`.

## Findings and changes

| Finding | Evidence | Change |
| --- | --- | --- |
| Main menu title overlaps the top bar | Observed on the live game, desktop cloud browser | Safe-area-aware top and side padding for the scrollable menu, including portrait widths |
| Circuit karts appear in the city | Confirmed in solo spawn code and Battlefield prop registry | Removed Racing Royal spawns and their collision props from Tirana; Racing Royal remains independent |
| Ordinary traffic uses simpler civilian GLBs | Confirmed in the renderer asset list | Mercedes, Audi and Ford originals replace sedan, sports, taxi and city-car visual templates; shared downloads and GPU resources |
| Race rival can have no visible model | `sport` state had no corresponding loaded template | Added the detailed `sport` template |
| A driver asset failure hides a loaded car | Reproduced against the actual collection visual class | Car loads independently; a driver may attach later and still yields to the player |
| Detailed model swaps need matching cabin and body dimensions | Covered by regression test | Traffic separation and cockpit sockets use the same catalog as the new visuals |
| Context loss leaves a loading screen with no retry | Confirmed in runtime and UI | Saves progress, stops rendering and exposes Retry, rebuilding the runtime |
| A hidden page may resume when loading completes | Confirmed in async loading flow | Keeps the game paused; skips hidden-page rendering |

All ten collection GLBs are unchanged. Civilian road models retain native scale, geometry and embedded PBR maps. Legacy wheel-name animation is not applied to these originals because mesh names do not guarantee the correct pivots or spin axes. Wheel animation for these replacements still needs an authored asset rig pass.

## Playable review and remaining gate

Run the existing Vite development server from `webapp` and open `/tirana-mobile-review.html`. This mounts the actual React/Three.js game in a portrait frame with 320, 360, 390 and 430 px choices, plus Street Career/Battlefield switching. It does not substitute a mock simulation or alter game state.

The cloud browser rejected both local preview addresses (`ERR_BLOCKED_BY_CLIENT`). The live Render game loaded far enough for a screenshot of its menu, but subsequent interactions and screenshots repeatedly timed out. A complete hands-on driving test, rendered verification of these changes, mobile frame-time measurement and the in-chat playable handoff are therefore **not complete**. No phone FPS or game-quality rating is asserted.

Before merging, play the changed branch on actual phones:

- At 320/360/390/430 px, confirm the menu, journal, map and buttons fit; enter and exit both cockpit/chase cameras.
- Walk to ordinary traffic and each named car; accelerate, brake, reverse, steer, collide and exit. Confirm front/rear orientation, full-sized car bodies, cabin positions and visible road obstacles.
- Start a race mission and confirm the rival has a visible detailed car.
- Interrupt the driver download; the vehicle must remain visible. Retry a failed game load and verify saved progress.
- Background/resume, open/close overlays and simulate graphics loss; ensure no held input or duplicate canvas/loop.
- Drive for at least ten minutes on a midrange Android phone and iPhone, measuring frame times and memory. Full-detail civilian models increase rendering cost, despite shared assets; tune measured budgets before calling this release-ready.

This is a reviewable quality pass, not a claim that the full game is bug-free or highly rated.
