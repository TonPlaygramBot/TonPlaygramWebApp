# Lana watercraft pilot

- Innerscene, [Personal watercraft](https://www.innerscene.com/tools/library/3d-parts/personal-watercraft-1956f692), CC0 1.0. The unmodified 5,310,508-byte GLB is reused from the previous Jet Ski Royal asset pack (Git blob 1d5c2bea9a0ddd137f4c1324d37f1239a1ff691f). Material batching happens at runtime.
- Channel path references the project's Existing OpenStreetMap data (ODbL).
- +0.70 m is a change to the solo game visual datum, not a claim about measured or navigable Lana depth. Three decorative moored craft use one original model. This feature does not add player-controlled jet skis or change simulation, collision geometry, Racing or mission state.
