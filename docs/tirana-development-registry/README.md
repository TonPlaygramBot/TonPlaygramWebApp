# Tirana evidence register proposal

Four original notes summarize official public-facing sources. No drawings, source photos,
textures, coordinates, or private property owner details are bundled. The registry is
independent of the game and should never be loaded as render input.

- **Built:** direct institutional evidence of existence/in-use. No opening date without evidence.
- **Observed construction:** documentary evidence of a work site, not evidence of present
  stage, built massing, or completion. Keep time of observation separate from approval.
- **Conditionally approved:** signed decision with unsatisfied or unverified issuance conditions.
  Do not promote without checking subsequent issue or construction evidence.
- **Agenda only:** listed for consideration with no signed outcome verified.

Parcel, street and existing mapped-feature identifiers are distinct from georeferenced points.
Do not import PDF topographic spot heights as coordinates. Treat `coordinates` and `crs` as
an inseparable pair requiring a checked coordinate reference system and a precise observation.
A date-stamped as-built record, verified recent public survey or appropriately licensed image and
a unique location match are required before publishing any changed game geometry.

See `build.log` for local validation. No production submission or asset rights implied.
