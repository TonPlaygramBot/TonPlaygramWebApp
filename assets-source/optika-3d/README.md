# Optika 3D source

Standalone fictional single-player game launched by TonPlayGram's Games catalogue.
No accounts, game wagers, payouts, external services, tracking or API dependence.

The shipped files are in `webapp/public/assets/optika-3d-v1/`. Both website and
native package use this path. Update the versioned path and Games catalogue
when making a later release to avoid mixing static runtime files across
deployments. Package attribution is provided in `assets/asset-credits.txt`.

Run from this directory with Node.js 24+:

```sh
npm ci
npm run build
node build-optika-actors.mjs ../../webapp/public/assets/optika-3d-v1/worlds
node --test test/*.test.mjs
```

The four original Optika environments (port, airfield, valley and snowy station)
and their authored lighting data are unchanged. All three actor assets were
replaced with project-original geometric GLBs without donor models or
photographic textures. The source bundle includes editable gameplay and UI
code. The public package also includes the original game stylesheet and static
HTML. No files outside the Optika package are generated by these commands.
