# Tirana original detail kit

Sixteen original procedural mesh recipes authored for TonPlaygram. No third-party
textures, font files, Google Maps imagery or extracted map meshes are included.
Units: metres. Source: `webapp/src/games/tirana-detail-kit/recipes.mjs`.

Building locations and footprint placement derive from © OpenStreetMap
contributors, ODbL 1.0, through the existing Tirana WORLD. Decorative fixture
positions are original approximations, not surveyed infrastructure positions.
Seven supplied ground-floor/park assets are not yet placed in the live scenes.
See `docs/tirana-map-and-detail-upgrade.md` for the exact integration and Blender
execution limits.
