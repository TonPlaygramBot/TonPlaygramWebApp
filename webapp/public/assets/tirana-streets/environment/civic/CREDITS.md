# Tirana civic detail assets

**Slatted park litter bin**: Innerscene original, released CC0.
[Author, model and CC0 dedication](https://www.innerscene.com/tools/library/3d-parts/slatted-park-litter-bin-6334976f).
The binary is the original author download (SHA-256 `441f814013fc7af89067b52a0a4d72f4c7dc24aca07b928113181a476820171d`).
The game batches the parts at load time without replacing the original materials.
Placements use mapped sidewalk basket points, © OpenStreetMap contributors (ODbL).
The mesh is representative; bin design is not asserted for each OSM point.
