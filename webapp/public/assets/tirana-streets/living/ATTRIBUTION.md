# Tirana Streets living-city assets

Files in this directory are parts of the game, not a separately licensed asset pack. Code licensing does not override each asset's terms. All assets are served locally; no paid downloads are required.

## Reused game sources

- **Chess Battle Royal Soldier**: Adobe/Mixamo Soldier from the pinned Three.js r164 example, with Idle, Walk, Run and TPose animations. Free game use under [Adobe Mixamo terms](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html). **Not CC0 and not open-source content**. Preserve Adobe's terms; do not redistribute it as a standalone asset pack. This replaces the previous Kenney mini character. Civilian/dealer/player/soldier roles currently share this human rig; individual clothing variants are a future art pass.
- **Kart Royale city**: the exact existing `../city.glb` Quaternius CC0 PBR building kit. 657 fitted footprint placements, with only nearby models rendered; original OSM footprints remain collision boundaries. The near/far meshes and embedded textures are reused, with surrounding shells also using the kit's PBR surface maps.
- **Ludo Battle Royal firearms**: the same 33 firearm/ordnance identifiers are represented. AK47, KRSV, Mosin, SigSauer, Smith, Uzi and animated shotgun models come from the sources already named by Ludo. Original individual CC BY 4.0 credits below take precedence over repository-level licenses. Imported historical Gunify paths in Ludo no longer all resolve; this package resolves available source files and Git LFS media and records shipped checksums.

## Model substitutions and scope

The Poly Pizza static download endpoint returned HTTP 403 in this workspace. No login or access restriction was bypassed. Quaternius pistol/rifle/shotgun/SMG meshes were obtained from the creator's CC0 OpenGameArt pack and converted to GLB. The unavailable revolver meshes use the attributed Smith revolver; the old Webaverse Glock, pistol and military meshes had no verified individual license, so those slots use licensed SigSauer/Smith/AK models instead. Quaternius robot-gun slots use the corresponding SMG/rifle prop. Launcher and explosive slots use Kenney CC0 blaster/hand-grenade props. These preserve gameplay IDs/categories but are **not 33 distinct, exact firearm models**. Molotov, gas-tank and dynamite slots currently use a shared explosive effect; they do not implement lingering fire or separate gas simulation.

Military response uses armed soldiers and military-colored Kenney SUVs at five stars. It does not include tanks or aircraft. The motorcycle mesh is Teh_Bucket's CC0 model, converted from OBJ; riding poses are layered over the human rig. The dealer has a fictional street stall, not a mapped real firearm shop.

Audio is original procedural Web Audio: weapon transients, impacts, explosions, reloads, footsteps, engine, siren and purchase cues. Existing Ludo remote sound previews were not copied without individual license verification.

## Rebuild

Use `webapp/scripts/build-tirana-living-assets.py CACHE OUTPUT SOURCE_JSON` with the GLB/glTF rows in `living-sources.json` that include `url`. It embeds dependencies, resolves Git LFS pointers and reduces textures. Use `optimize-tirana-glb.mjs FILE TRIANGLE_BUDGET` for static high-detail sources. `convert-tirana-obj.mjs SOURCE_OBJ OUTPUT_GLB` converts the attributed CC0 OBJ downloads. Python requires Pillow; the Node tools use this webapp's existing Three.js and meshoptimizer dependency. Texture URL substitutions and mobile glass settings are recorded by the source builder. Compare output SHA256 values with the manifest when preparing a release.
