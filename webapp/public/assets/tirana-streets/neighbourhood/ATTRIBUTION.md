# Tirana neighbourhood assets

- Geographic data and derived footprints: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright). Object IDs and source references are retained in the source archive, runtime dataset and Blender object metadata.
- Original authored facade/storefront detailing and asset-building scripts: CC0-1.0. Buildings contain OSM-derived footprints as identified above.
- PBR plaster: [Poly Haven — plastered_wall_02](https://polyhaven.com/a/plastered_wall_02), CC0-1.0. Diffuse, OpenGL normal and roughness maps were sourced from the project's hash-verified 2K originals, resized and shared at 1K for runtime. Other surface colors are authored PBR values.
- No Google Maps/Street View imagery is redistributed. Ground photos informed limited exterior details only; dimensions, unseen sides and generic businesses are approximate.

See `docs/tirana-ali-demi-neighbourhood.md` and `assets-source/tirana-neighbourhood/` in the repository for coverage, source receipts, editable Blender scene, assumptions and rebuild commands. `manifest.json` records the exact runtime file hashes and sizes.
