# Original Blender cast — source and portrayal notes

All seven GLBs and the editable Blender file are original TonPlaygram meshes,
licensed under the repository's MIT terms. Generated with Blender 4.5.3 LTS.
The five named figures are stylized fictional game portrayals. There are no
photographic face textures, scanned bodies or extracted Google assets.

Reference photos were visually inspected for hair, facial silhouette and clothing
only. No reference photo is redistributed in this asset directory or the game.

The police officer and water-cannon truck are original fictional models. Their
proportions and insignia are illustrative, not replicas of a specific police unit.
GLB names, hashes and sizes are recorded in `manifest.json`. The `Throw` animation
is exported on each human skeleton; runtime hand-target IK synchronizes projectiles
with the actual hand and supports flags. The truck exposes `turret` and `nozzle`.
