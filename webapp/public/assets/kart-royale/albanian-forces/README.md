# Racing Royal — Albanian Forces

Optimized self-contained glTF 2.0 exports: 8 vehicles and 6 rigged characters,
with full and `-lod.glb` versions. Embedded JPEG/PNG textures, named wheel/steering
pivots, and character Idle/Walk clips are preserved. Metres, Y-up, +X vehicle
forward; the game adapter turns/scales these visuals.

`manifest.json` records sizes, unique-mesh triangles and clips. `thumbnails/`
contains original previews. `ATTRIBUTION.md` and `notices/` preserve mixed-license
credits and notices. `PACK-README.md` and `REFERENCES.md` preserve source fidelity
notes; their original source-directory layout is not duplicated here.

See `docs/racing-royal-albanian-forces.md` in the repository for integration,
rebuild instructions and limitations. Editable Blender files remain in the
supplied archive.
